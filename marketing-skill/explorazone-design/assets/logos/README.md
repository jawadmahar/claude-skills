## Rules

- Always reach for the SVG first; PNGs are a fallback for environments that won't load SVG.
- Clear-space rule: one capital "E" height on all sides.
- Never crop the wordmark. If space is tight, drop to the emblem.
- Never re-type "EXPLORAZONE" in any font; always place the supplied lockup.
